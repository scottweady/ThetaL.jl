API reference

ThetaL — Module
ThetaL

Boundary evolution: θ–L motion of closed plane curves (Hou, Lowengrub & Shelley 1994). N curves move with outward normal velocities that depend on all of them, (U₁, …, UN) = F(X₁, …, XN; t), given by the caller as one function; the stiff part of each curve's motion, whose rate per Fourier mode (the small-scale symbol) the caller gives too, is treated exactly by an exponential integrator, and the rigid part of each curve's motion is integrated exactly. Nothing here knows how the velocity is computed.

A curve Γ (counterclockwise) is represented by its tangent angle θ(α) and length L, with α ∈ [0, 2π) an equal-arclength parameter (sα = L/2π), sampled at N equispaced α. The state holds the periodic part φ = θ − α, the length L and the point x₀ = x(α = 0). A state is made from any parametrization of the curve (`fromcurve, spectral) or from points already at equal arclength (fromarclengthsamples`).

Conventions: τ = (cos θ, sin θ), outward normal n = (sin θ, −cos θ), κ = θs. The points move with xt = U n + T τ (U the given normal velocity, T chosen to keep equal arclength): Lt = ∫₀^{2π} U θα dα, Tα = Lt/2π − U θα, T(0) = 0, θt = (T θα − Uα)/sα, x₀,t = U(0) n(0). Rigid motion: the normal velocity is split as U = Urig + Ud, with Urig = V·n − Ω (x − xc)·τ the rigid motion closest to U (`rigidpart). The tangential velocity is the rigid one plus that of U_d from the equation above, so a rigid motion does not move the points along the curve: it adds Ω to θ_t, and moves x₀ on the rigid motion, which the step integrates exactly. A rigid translation and rotation are therefore exact at any Δt. Small scales: θ_t ≈ σ(q) φ̂_k with σ the symbol, the growth rate of a mode of wavenumber q = 2π|k|/L (σ < 0 damps), frozen per curve at the start of each step. The one-step schemes (ETDRK2,ExpEuler`) are exponential Runge–Kutta methods: the remainder R = θt − σφ̂ is explicit, integrated against e^{σt} with ϕ-function weights. A spectral filter is applied to φ after each stage and to Ud before differentiation.

Code map (src/):

  • grid/: periodic grid functions (fourier.jl: wavenumbers, spectral derivative, double_grid, halve_grid; real FFTs on half spectra, complex ones for curves as x + iy) and their work arrays (work.jl: FFT plans and scratch vectors per N, kept per task).
  • Each state caches what is computed from it more than once (its half spectrum, θ_α, its points); the step makes its states with their spectra, so a step needs five real FFTs per stage, and one complex pair per new state.
  • curves/: the state (state.jl), states from curves (construct.jl), utilities for callers (measures.jl).
  • stepping/: the stiff symbol (symbols.jl), the spectral filter (filter.jl), the kinematics and the rigid split (kinematics.jl), the schemes and their weights (schemes.jl), the generic step (step.jl).
  • problem/: the velocity protocol (evaluation.jl: Evaluation, StepFailure), CurveProblem, the state carried with the curves (carried.jl: CurveField, BulkState; its step in stepping/carried.jl), and the stiffness of a velocity measured against its symbol (symbol_check.jl: measure_symbol, check_symbol).
  • integrator/: ThetaLIntegrator, init, advance!, step! (integrator.jl), curve edits (edits.jl), checkpoint (checkpoint.jl).
  • drivers/: evolve, solve, Evolution, save_curves.

Outside src/: ext/ThetaLDotPlotsExt.jl, dotplot of curves and of an Evolution when DotPlots is loaded.

Curves

ThetaL.ThetaLState — Type
ThetaLState(φ, L, x0)

State of a curve: φ = θ − α at the N grid points, length L, and x₀ = x(α = 0); length(X) is N. A state is a value: what is computed from it (its spectrum, curvature, points) is kept with it, so never change φ in place; make a new state.

ThetaL.from_curve — Function
from_curve(γ, N; tol=1e-6) -> ThetaLState
from_curve(γ; tol=1e-6, N=64, Nmax=16384) -> ThetaLState

The state of the closed counterclockwise curve ξ ↦ γ(ξ) (2π-periodic; a point is anything indexed by 1, 2) with N points at equal arclength, the first at γ(0). Spectral: γ is sampled at M equispaced ξ, M doubled until the Fourier tails of γ and of its speed are below tol/100; the arclength is the antiderivative of the speed, the points are found by Newton on it, and θ is the angle of γξ there. Without N, N is doubled from N until the tail of the φ spectrum (`spectraltail) is below tol/100, or until doubling would exceedNmax`.

ThetaL.from_arclength_samples — Function
from_arclength_samples(points) -> ThetaLState

The state of the closed counterclockwise curve through points: N points equispaced in arclength, the first at α = 0. The tangent comes from the spectral derivative of the trigonometric interpolant of the points.

ThetaL.curve_function — Function

Trigonometric interpolant of the curve: returns z(α) as a function (Vec2), using the closure-corrected Fourier series of x_α = (L/2π)(cos θ, sin θ).

ThetaL.curve_points — Function

Grid points x(α_j).

ThetaL.tangent_angles — Function

Tangent angles θ = α + φ at the grid points.

ThetaL.curvature — Function

Curvature κ = θs = (1 + φα)/s_α at the grid points (spectral; positive where the curve is convex).

ThetaL.arclength_derivative — Function
arclength_derivative(X, f)

The derivative ∂f/∂s = (2π/L) fα of a periodic function f given at the grid points of X (spectral, Nyquist mode dropped): e.g. κss = arclength_derivative(X, arclength_derivative(X, curvature(X))).

ThetaL.velocity_components — Function
velocity_components(X, u) -> (U, W)

Normal and tangential parts of the velocities u at the grid points of X: U = u·n, W = u·τ.

ThetaL.velocity_vectors — Function

The velocities U n + W τ at the grid points of X (the inverse of velocity_components).

ThetaL.curve_moments — Function
curve_moments(X) -> (A, M)

Area A and first moment M = ∫ x dS of the region inside the curve, A = ½∫ x × xα dα and M = ⅓∫ x (x × xα) dα by the trapezoidal rule (spectral).

ThetaL.area — Function

Area of the region inside the curve.

ThetaL.centroid — Function

Centroid of the region inside the curve.

ThetaL.perimeter — Function

Length of the curve.

ThetaL.spectral_tail — Function

Tail of the φ spectrum, the largest |φ̂_k|/N in the band N/2 ± N/8: how well N resolves the curve.

ThetaL.double_grid — Function
double_grid(f) / double_grid(X)

Trigonometric interpolation of a periodic grid function from N to 2N points (zero padding, the Nyquist mode split in two), or of the φ of a state.

ThetaL.halve_grid — Function
halve_grid(f) / halve_grid(X)

Spectral truncation of a periodic grid function from N to N/2 points: the modes |k| < N/4 kept, the two modes ±N/4 folded into the new Nyquist mode, the rest dropped. Or of the φ of a state. The inverse of double_grid for a function resolved on N/2 points.

Utilities

ThetaL.min_distance — Function
min_distance(states; within = true) -> Float64

The smallest distance between grid points of different curves, and, with within, between points of one curve that are more than a quarter of its length apart along it (a neck). The small-scale decomposition fails where this becomes comparable to the grid spacing; use it to stop, refine or shorten the step. O(N²) per pair of curves.

ThetaL.curve_integral — Function
curve_integral(X, f) -> ∫ f ds

The integral along the curve X of f given at its grid points (equal arclength: the trapezoidal rule, spectrally accurate for smooth periodic f).

ThetaL.offset_curve — Function
offset_curve(X, δ) -> ThetaLState

The parallel curve at distance δ along the outward normal (δ < 0: inward), on the same number of points: the points x(α) + δ n(α), put back at equal arclength (its length is L + 2πδ, its area A + δL + πδ²). Valid while δ > −1/max κ (the parallel curve of a convex part stays smooth only so far inward).

ThetaL.remove_area_rate — Function
remove_area_rate(states, U; per_curve = true) -> U′

The normal velocities with the part that changes area taken out: ∫ U′ ds = 0 on every curve (per_curve = true), or one constant subtracted from all curves so that only the total area is kept, Σᵢ ∫ U′ᵢ ds = 0 (per_curve = false, e.g. Ostwald ripening, where area moves between particles). Area then drifts only at the time error of the step.

ThetaL.frame_velocity — Function
frame_velocity(X, U; rigid = :full, W = nothing) -> Vector{Vec2}

The velocity of the tracked grid points of X under the normal velocity U: U n + T τ, with T the tangential velocity of the step (the rigid motion's, plus the equal-arclength one of the deformation, T(0) = 0). This is what a moving bulk mesh attached to the curve's points follows. rigid and W as in rigid_part (the step passes W when the problem has fields transported along the curves).

ThetaL.rigid_part — Function
rigid_part(X, U; mode = :full, W = nothing) -> (motion::RigidMotion, U_deformation)

The rigid motion in the velocity of the curve X, and the rest of its normal velocity U. The motion is the translation V and rotation rate Ω about the center xc (the mean of the grid points), fitted by least squares on the grid (equal arclength); `Udeformation = U − Urig`, with Urig = V·n − Ω (x − x_c)·τ its normal velocity.

  • Without W, the fit is to the normal velocity: U_rig closest to U. A curve near a circle hardly shows its rotation in U (a circle turning about its center has U = 0), so its Ω is then poorly determined: noise in U becomes a rotation rate. The step is built so that this does not move the curve (only the points slide along it).
  • With W (the material's tangential velocity), the fit is to the whole velocity u = U n + W τ: V the mean of u, Ω = Σ (x − xc) × u / Σ |x − xc|², well determined for every curve.
  • mode = :full: translation and rotation; mode = :translation: translation only; mode = :none: no rigid part (NO_RIGID_MOTION, U returned as it is).
ThetaL.RigidMotion — Type
RigidMotion(translation, rotation_rate, center)

A rigid velocity field u(x) = translation + rotationrate · ẑ × (x − center) (`rigidvelocity(m, x)`).

ThetaL.rigid_velocity — Function

The velocity of the rigid motion m at the point x.

ThetaL.measure_symbol — Function
measure_symbol(problem, states = nothing; curve = 1, k = nothing, ε = 1e-4, windows = 1, t = 0.0,
               warm = nothing, tol = 1e-6, Nmax = 16384)
measure_symbol(integ; curve = 1, k = nothing, ε = 1e-4, windows = 1)
    -> (; k, q, σ, λ, given)

The growth rate of small-scale modes of curve curve under the problem's velocity, measured: φ of that curve is perturbed by ±ε w(α) cos(k(α − α₀)) and ±ε w(α) sin(k(α − α₀)) (L, x₀ and the other curves held), θ_t is computed from the velocity as the step does (the rigid part taken out per problem.rigid, no filter), and the rate λ = ⟨p, J p⟩/⟨p, p⟩ of the packet p = w e^{ik(α−α₀)} is read from the central differences (four evaluations per k and window). states default to the problem's curves (parametrizations resolved to tol, as init does); the integrator's method measures at its time, states, context and carried state.

  • k: the Fourier modes (default: six from 2 to N/4, about geometrically spaced);
  • ε: the amplitude of the perturbation of φ (radians). The central difference has an O(ε²) error; noise η in U enters λ as about q η/ε: raise ε for a velocity computed to a loose tolerance;
  • windows: 1, the whole curve (w ≡ 1: λ is the Fourier coefficient (J e^{ikα})_k/N, the mode-averaged rate); m > 1, m Gaussian packets centered at α₀ = 2π(j − 1)/m, of width π/(m√2) in α: the local rate, which is what a frozen symbol must bound on a curve whose stiffness varies along it (anisotropy);
  • t, warm: the evaluations' time and the warm start of the first (each passes its ctx to the next).

Returns k, q = 2π k/L, the measured σ (Re λ, the most negative over the windows), λ (complex, one column per window: an imaginary part is a transport rate, which the real symbol leaves explicit), and given (the problem's symbol at q, zero without one). The velocity is told ev.kind = :probe.

ThetaL.check_symbol — Function
check_symbol(problem, states = nothing; dt = nothing, scheme = ETDRK2(), curves = nothing, warn = true, kw...)
check_symbol(integ; dt = nothing, curves = nothing, warn = true, kw...)
    -> (; ok, dt_limit, curves)

Whether the problem's symbol bounds the stiffness of its velocity: the rates are measured (measure_symbol; kw are passed on: k, ε, windows, …) on each curve of curves (default all), and for each mode the largest step dt_max that the scheme takes stably is computed, with the symbol σg treated exactly and the rest, (λ − σg)φ̂, explicitly: per mode the step multiplies φ̂ by G(σg h, (λ − σg)h) (from the scheme's weights), and dt_max is the first h at which |G| exceeds max(1, e^{Re λ h}) (Inf: stable at every step).

For ETDRK2 and real rates the condition at large steps is 0 ≤ λ/σg ≤ 3/2: a symbol may overstate the true rate (the mode is then damped less per step), and must not understate it by more than a third (ExpEuler: 0 ≤ λ/σg ≤ 2, by up to half). Beyond that a step limit Δt ~ 1/|λ| remains at that mode, which a stiff velocity turns into Δt ~ q^{−p}.

ok: with dt, whether dt ≤ dt_limit; without, whether no measured mode has a limit (dt_limit = Inf). A finite limit at low q only can be the explicit treatment of a part that is not stiff (pass the step you plan as dt). curves[c] is the measurement of curve c with dt_max. With warn, a failed check warns with the worst modes. Only the measured modes are checked: the ratio λ/σ_g at the largest measured q stands for the higher ones.

The problem and the velocity protocol

ThetaL.CurveProblem — Type
CurveProblem(curves, velocity; symbol = nothing, rigid = :full, tags = nothing, validate = nothing,
             fields = (;), bulk = nothing)

What is evolved:

  • curves: a vector of closed counterclockwise curves, each a parametrization ξ -> (x, y) (2π-periodic) or a ThetaLState;
  • velocity(states, ev::Evaluation; warm) -> U or (; U, ctx, W, rates, ydot): the outward normal velocity of every curve at the grid points of its state (one vector per curve), all curves at once; ctx is any context the caller wants back as warm at the next evaluation (a warm start). With carried state: W the material tangential velocity (one vector per curve; needed when a field is transported), rates the fields' rates (a named tuple, one vector per curve each; a field left out has rate 0) and ydot the bulk state's rate. Throw StepFailure(reason) to reject a step;
  • symbol: the growth rate σ of a small-scale mode of a curve, θ_t ≈ σ φ̂, as a function σ(q) of the wavenumber q = 2π|k|/L along the curve, or σ(q, X) of it and the curve X (a ThetaLState), frozen per curve at the start of each step: q -> -q^2 for U = −κ; nothing for none;
  • rigid: which rigid motion is taken out of U and integrated exactly, :full (translation and rotation), :translation or :none;
  • tags: one opaque tag per curve, carried through edits and checkpoints, never interpreted;
  • validate(states) -> Bool: optional; a step whose end state fails it is rejected;
  • fields: fields on the curves, a named tuple of CurveFields ((; c = CurveField(c0))); their values at each stage are ev.fields.c (one vector per curve), at the integrator's time integ.fields.c;
  • bulk: a BulkState, one vector carried with the curves; its stage value is ev.bulk, integ.bulk its value.

velocity and symbol may be replaced between steps (prob.velocity = …); the change applies from the next step.

ThetaL.CurveField — Type
CurveField(init; transport = :density, symbol = nothing)

A field on the curves: one value per grid point of each curve, advanced with them.

  • init: the initial values, for every curve the same (a number, or a function X -> values of the curve's state), or one entry per curve (each a number, a vector of the curve's N values, or such a function). A function or a number is also used for curves added later (add_curve!).
  • transport: how the field moves along the curve, where the material moves tangentially at W (returned by the velocity) and the grid points at the frame's T (which keeps them at equal arclength):
    • :density: a conserved density per unit length; the step adds ct = −((W − T)c)s − c L_t/L, which keeps ∫c ds exactly on the grid (the velocity's rate is then the source, e.g. adsorption or surface diffusion);
    • :material: a value carried by the material points: ct = −(W − T) cs;
    • :none: the velocity's rate is the whole c_t at the grid points.
  • symbol: the stiff part of the field's own rate, as the curve's symbol: the growth rate σ(q) or σ(q, X) of a mode of wavenumber q along the curve (surface diffusion D c_ss: q -> -D * q^2), treated exactly by the step.
ThetaL.BulkState — Type
BulkState(y0; symbol = nothing)

A state off the curves, one vector y advanced with them (the unknowns of a bulk field with memory, a few scalars). Its rate is the velocity's ydot. symbol: the growth rates σ of its components, a vector (y_t ≈ σ y for the stiff part, diagonal: a pseudo-spectral field's −Dk²), treated exactly by the step; nothing for none.

ThetaL.Evaluation — Type
Evaluation

What a velocity evaluation is for, passed to velocity(states, ev; warm):

  • t: the time of the evaluation (exact: at the end of a step, the time stepped to);
  • kind: :init (the start of a run, or the first evaluation after a curve edit), :stage (inside a step) or :end (the end of a step; its result is also the next step's first stage); :probe for a perturbed state of measure_symbol/check_symbol (no step: stage = 0, h = 0.0; nothing of it is kept);
  • stage, c: the stage index and its fraction of the step (0 and 0.0 at :init, c = 1 at :end);
  • h: the step being taken (0.0 at :init);
  • attempt: 1, or more when the step is a retry after a rejection;
  • ids, tags: per curve, a stable id and the caller's opaque tag (ThetaL never interprets tags);
  • topology: a counter bumped by every curve edit and change of N; a warm start keyed on it knows when the curves have changed;
  • base: the states at the start of the step (a moving bulk mesh forms its displacement from them);
  • fields: the fields on the curves at this stage, a named tuple (ev.fields.c: one vector per curve);
  • bulk: the bulk state at this stage (nothing without one).
ThetaL.StepFailure — Type
StepFailure(reason)

Thrown by a velocity function to reject the step it is evaluated for (a solver that did not converge, a state it cannot handle). advance! catches it, leaves the integrator as it was and returns :rejected, with reason in integ.stats.last_rejection. Any other exception propagates (the integrator is still left as it was).

Schemes and the step

ThetaL.OneStepScheme — Type

Supertype of the one-step schemes of thetaL_step (ETDRK2, ExpEuler).

ThetaL.ETDRK2 — Type
ETDRK2(; filter_order = 36, filter_cutoff = 0)

Exponential Runge–Kutta of order 2 (Hochbruck & Ostermann 2005, c₂ = 1/2), the default: two velocity evaluations per step (the one at the end is the next step's first stage). Embedded exponential Euler: an error estimate available after the midpoint stage, before the end evaluation. Keeps a state at rest fixed with a symbol present; with no symbol it is the explicit midpoint rule.

ThetaL.ExpEuler — Type
ExpEuler(; filter_order = 36, filter_cutoff = 0)

Exponential Euler, order 1: one velocity evaluation per step. For checks and debugging; with no symbol it is the explicit Euler method.

ThetaL.SpectralFilter — Type
SpectralFilter(; order = 36, cutoff = 0)

The exponential filter of the θ–L step: mode k is multiplied by exp(−36 (|k|/kc)^order), and modes |k| ≥ kc are removed. It is applied to φ after every stage and to the deformation part of U before it is differentiated.

  • order: the steepness; 0 turns the filter off.
  • cutoff: kc as an integer; 0 means kc = N/2 (the Nyquist mode); :auto means "set it from noise_cutoff after the first velocity evaluation" (the integrator does this once and keeps the integer).
ThetaL.noise_cutoff — Function
noise_cutoff(states, U, symbol) -> kc

A filter cutoff above the noise that the normal velocities U of the states carry. An error δÛk in U about flat in k, and all that U holds at high k for a smooth start, is measured as ε = max |Ûk|/N over k ≥ N/4. It enters φ through θt ∋ (2π/L)(ik)Ûk, against which the step damps at the rate −σk from symbol, so the noise settles at φ̂k ≈ (2π/L) k ε / |σ_k|. The cutoff is placed so the filter keeps 99 % of the mode where the φ spectrum meets this floor (σ = 0.99 at 0.8 kc), and is at least 32, so curves that start as circles can deform.

ThetaL.thetaL_rhs — Function
thetaL_rhs(X, U, filt) -> (θ_t, L_t, x₀_t)

Time derivatives of the state X under the normal velocity U (filtered by the mode weights filt first): θt on the grid, Lt, and the velocity of the point x₀. No rigid part is taken out here (the step does that).

ThetaL.thetaL_step — Function
thetaL_step(scheme, problem, states, U, t, t_end; warm = nothing, ids, tags, topology = 0, attempt = 1,
            errtol = Inf, fields = nothing, bulk = nothing, aux = nothing) -> StepResult

One step of all states from t to t_end (exactly) with the scheme, the velocity, symbol, rigid mode and validate of problem, starting from the velocities U at t and the context warm. With state carried with the curves: its values at t (fields[f][c], bulk; by default the problem's initial values) and the W, rates and ydot of the evaluation that gave U (aux, as a velocity's named tuple; required then). Stateless: the integrator (advance!) is built on it. A step is rejected (nothing changed) when a stage has a non-positive length, when the embedded error estimate exceeds errtol (checked before the end evaluation), when validate fails, or when the velocity throws StepFailure.

ThetaL.StepResult — Type
StepResult

The outcome of thetaL_step: status (:success or :rejected), reason (why a step was rejected: :nonpositive_length, :error_estimate, :invalid_state, or the reason of a StepFailure), the new states, their velocities U, the context ctx of the last evaluation, the rigid motion of each curve over the step, the embedded error_estimate (NaN if the scheme has none), the number of velocity evaluations made, and the state carried with the curves: fields (one vector per field and curve, fields[f][c]), bulk and the last evaluation's W, rates and ydot (aux). On rejection the states, velocities, context and carried state are those given.

For scheme authors (not exported; see Adding a scheme):

ThetaL.stage_nodes — Function

The stage nodes cᵢ of a scheme (fractions of the step; c₁ = 0, the start of the step).

ThetaL.scheme_weights — Function
scheme_weights(scheme, z) -> (A, b, b̂)

The weights of one mode at z = σh (σ the symbol's rate): A[i][j] for stage i from stage j < i, b[i] for the end, b̂[i] for the embedded solution (equal to b when there is none). Tuples, so nothing is allocated.

ThetaL.has_error_estimate — Function

Whether the scheme has an embedded solution for an error estimate.

ThetaL.with_filter — Function

The same scheme with another spectral filter.

ThetaL.evaluations_per_step — Function

Evaluations of the velocity per step: one per stage after the first (the first reuses the previous end), and the end.

The integrator

ThetaL.ThetaLIntegrator — Type
ThetaLIntegrator

The state of a run, made by init(problem, scheme). Read-only fields (change them only through advance!, step! and the curve edits):

  • t: the time; states::Vector{ThetaLState}: the curves; U: their normal velocities at t (nothing after an edit, until the next step evaluates them);
  • ctx: the context of the last committed velocity evaluation (handed to the next as warm);
  • ids, tags: per curve, a stable id and the caller's tag; topology: bumped by every edit and change of N;
  • rigid::Vector{RigidMotion}: each curve's rigid motion over the last step;
  • fields: the fields on the curves at t, a named tuple (integ.fields.c: one vector per curve); bulk: the bulk state at t (nothing without one);
  • stats::IntegratorStats.

Settable between steps: scheme (or its filter), problem.velocity, problem.symbol; they apply from the next step. Vectors are replaced, never changed in place, so a reference to integ.states or integ.U stays valid.

ThetaL.IntegratorStats — Type

Counts of a run: steps (accepted), evaluations (velocity calls), rejections, consecutive_rejections, error_estimate of the last step tried (NaN if the scheme has none), last_rejection (its reason), last_step (the size of the last accepted step; NaN before the first).

ThetaL.init — Method
init(problem, scheme = ETDRK2(); t0 = 0.0, U = nothing, ctx = nothing, from = nothing, tol = 1e-6,
     Nmax = 16384) -> ThetaLIntegrator

Start a run of problem with scheme. Curves given as parametrizations are resolved to tol (N a power of two from 64, at most Nmax). The velocities at t0 are evaluated (kind = :init, warm = ctx) unless U is given. from = checkpoint(integ) restarts a run instead (its time, curves, velocities, ids, tags, resolved filter cutoff and carried state). The fields start from the problem's CurveFields, the bulk state from its BulkState.

ThetaL.advance! — Function
advance!(integ, t; errtol = Inf) -> :success or :rejected

One step from integ.t to t (exactly: integ.t == t afterwards). If the velocities are not current (after a curve edit) they are evaluated first (kind = :init). A step is rejected, and the integrator left exactly as it was, when the velocity throws StepFailure, a stage has a non-positive length, the embedded error estimate exceeds errtol (checked before the end evaluation, so that costs one evaluation less), or validate fails; the reason is in integ.stats.last_rejection, and a retry is told attempt = 2, 3, ….

ThetaL.step! — Method
step!(integ, dt; errtol = Inf) -> :success or :rejected

advance!(integ, integ.t + dt; errtol). Use advance! to land exactly on a given time.

ThetaL.progress_line — Function
progress_line(integ; dt = integ.stats.last_step) -> String

One line on the run so far: the time, the accepted steps (and the rejected ones, if any), the step Δt (by default the last one), the number of points N (its range and the number of curves, for several) and the velocity evaluations. Printed by evolve and solve with verbose = true (with Δt the mean step since the previous line); print it yourself when driving the integrator by hand.

ThetaL.double_grid! — Function

Curve c on twice the points (its velocity interpolated with it).

ThetaL.halve_grid! — Function

Curve c on half the points (spectral truncation; its velocity truncated with it).

ThetaL.set_curve! — Function
set_curve!(integ, c, curve; fields = nothing)

Replace curve c by curve (a ThetaLState or a parametrization); its id and tag are kept. Its fields are kept, resampled to the new N if it changes, or set from fields (a named tuple: per field a number, a vector or a function X -> values).

ThetaL.evolve — Function
evolve(curve, U, tspan; dt, symbol = nothing, saveat = nothing, tol = 1e-6, Nmax = 16384, scheme = ETDRK2(),
       rigid = :full, callback = nothing, coarsen = false, verbose = false,
       adaptive = false, errtol = 1e-5, dtmin = 0.0, dtmax = Inf) -> Evolution

Move the closed counterclockwise curve over tspan = (t0, t1) with outward normal velocity U. One call for simple scripts; init/advance! for anything more.

  • curve: a parametrization ξ -> (x, y) (2π-periodic), a ThetaLState, or a vector of either: several curves that move together.
  • U(X, t): the normal velocity at the N points of the curve X (a ThetaLState: use curve_points(X), curvature(X), tangent_angles(X), …; for a velocity field u, velocity_components(X, u)[1]); for several curves U(Xs, t), one vector per curve. Its rigid part is integrated exactly (rigid, as in CurveProblem).
  • symbol: the growth rate σ of a small-scale mode, θt ≈ σ φ̂, as σ(q) of the wavenumber q = 2π|k|/L along the curve or σ(q, X): q -> -q^2 for U = −κ, q -> -q^4 for U = κss; nothing: none.
  • dt: the step, a number or a function dt(X, t) (dt(Xs, t) for several curves). With adaptive, optional: a number is the first step (default: a guess from the velocity), a function a bound on each step (a stability limit, as dtmax).
  • adaptive = true: the step is chosen from the embedded error estimate of the scheme (ETDRK2; an ArgumentError for a scheme without one) and kept below errtol (advance!'s, an absolute bound per step on the largest of |Δφ|, |ΔL|/L and |Δx₀|/L between the step and its embedded first-order one, over the curves). The next step is h·clamp(0.9 (errtol/err)^½, 0.2, 5) (err ∝ h²); a step over errtol is rejected before its end evaluation (one evaluation lost) and retried with the step so shrunk, a step rejected for another reason (the velocity threw StepFailure, a non-positive length, validate) with a quarter of it. The steps stay within dtmin and dtmax; below dtmin, or after 30 rejections in a row, the run stops with an error. Small steps where the curve moves fast (an initial layer), large ones where it relaxes.
  • saveat: the times to keep: nothing (the start and the end), a spacing, or a list. Steps land on them exactly (with adaptive, the last step before a saved time is stretched by up to 10% or the last two split evenly, so that no sliver is left, and the step from before resumes after it).
  • tol: N is the smallest power of two from 64 whose φ tail (spectral_tail) is below tol/100; it is doubled (up to Nmax) after any step whose tail exceeds tol, and with coarsen = true halved when the tail on half the points has stayed below tol/100 for 10 steps. Without coarsen, N never comes back down: one step of noise in a computed velocity is enough to double it for the rest of the run (ETDRK2(filter_cutoff = :auto) damps that noise). Set Nmax to what your velocity can afford: for an O(N²) solve the default 16384 is out of reach.
  • callback(integ): called after every accepted step; return :stop to end the run. It may edit the curves.
  • verbose: print a line at the start and at each saved time (progress_line: t, steps, rejections, the mean Δt since the previous line, N, evaluations), with the wall time so far, and a line whenever N changes (when, and why).

Without adaptive a rejected step is an error (the step is given: there is nothing to retry with); to control steps otherwise, use the integrator.

ThetaL.solve — Method
solve(problem, scheme = ETDRK2(); tspan, dt, saveat = nothing, tol = 1e-6, Nmax = 16384, callback = nothing,
      coarsen = false, verbose = false, adaptive = false, errtol = 1e-5, dtmin = 0.0, dtmax = Inf) -> Evolution

Run problem over tspan as evolve does (dt a number or dt(Xs, t); or adaptive = true, with dt optional), from init(problem, scheme).

ThetaL.Evolution — Type
Evolution

The result of evolve and solve: the saved times t, the curves there (curves: a ThetaLState each for evolve of one curve, otherwise a vector of states per time), the curve ids at each saved time, the number of accepted steps and of rejected ones (rejections, with adaptive); with state carried with the curves, fields (per saved time a named tuple, one vector per curve each: sol.fields[i].c) and bulk (per saved time). sol(t) is the curves saved at time t. With DotPlots loaded, dotplot(sol) draws them in the terminal, one frame per saved time.
